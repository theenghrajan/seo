# SEO / Tracking task notes

## File conventions
- Task folders are named after the AC task (e.g. `Google Ads Tracking [Lead Gen]/`); per-site work goes in a subfolder named after the domain (e.g. `grovedentalaz.com/`).
- Always write notes as **Markdown (`.md`)**, never `.txt`.
- Per task reply, files dated `MM-DD-YYYY`:
  - `MM-DD-YYYY-log.md` — what was checked and the findings (technical detail is fine here).
  - `MM-DD-YYYY-solutions.md` — fixes in order; links to the comment file instead of repeating the draft.
  - `MM-DD-YYYY-comment.txt` — the final AC comment, plain text, pasted as-is (the only `.txt` exception).
- Draft AC comments: plain language for non-technical PMs, start with "As per comment #N,", end with "Thanks!" only. Never post to AC — the user pastes them.
