PPC calls go missing or land in the wrong action, and only on the first page a visitor sees after clicking an ad. Direct tests with ?id=ppc skip that case, so everything looked fine.

What happens on the landing page

First page from an ad

  1. Visitor clicks ad → arrives from google.com with ?id=ppc. No query_string cookie yet.
  2. GTM rule "block 858/416 for PPC" checks the cookie → empty → 858 and 416 call tags fire.
  3. Google swaps 858-299-2878 / 416-7071 with its forwarding numbers before our script loads.
  4. Swap script shows 619-786-2032 in the text, but the header phone icon links to the SEO number 619-786-2031. Its first pass runs before the PPC cookie exists, so "search engine" wins.
  5. PPC call tag (cleanup of LeadTracker tag) fired already, before any swap. Nothing to replace.
Result Calls count under the 858/416 actions, or reach 2031 via the icon. Measured: 858 tag at 1.6s, 416 at 1.8s, PPC tag at 2.0s, swap script at 2.7s.

Second page onwards

  1. Cookie query_string now contains ppc (set by the swap script on page 1).
  2. GTM blocks the 858 and 416 call tags.
  3. Swap script shows 619-786-2032.
  4. PPC call tag fires; Google can replace 2032 with its forwarding number.
Result Tracked correctly. This is the case FED tested.

d("//leadtracker.smartsites.com/conditional-replacer-3.js",function(){
  a("[href^='tel:']").each(function(){a(this).attr("href","tel:"+a(this).attr("href").replace(/\D/g,""))});
  var ppc=/[?&]id=ppc(&|$)/.test(location.search)||/query_string=[^;]*ppc/.test(document.cookie);
  var cond={BY_PARAMS:{text:"619-786-2032",params:{id:"ppc"}}};
  if(!ppc)cond.SEARCH_ENGINE={text:"619-786-2031"};
  a.each("(619) 416-7071;6194167071;858-299-2878;8582992878;(858) 299-2878;+1 (619) 874-7900;6198747900;619-416-7071;(619) 555-0123;6195550123".split(";"),function(c,b){
    ConditionalReplacer({rootSelector:a('a[href^="tel:"],.elementor-icon-list-text,.elementor-icon-box-title,.elementor-icon-box-description,.elementor-button-text'),
      placeholder:b,conditions:cond}).run(a)});
  window.dataLayer.push({event:"ss_number_swapped"});
});
