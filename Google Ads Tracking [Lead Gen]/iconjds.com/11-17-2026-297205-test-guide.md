## State (11-17)
GTM Default Workspace, not published:
- **SS - LeadTracker (Trench Box Quote Click)** (Tag B) — Custom HTML, trigger **SS - Trench Box Get Your Quote Click** (new: Click - All Elements, Click Text contains `Get Your Quote`, Page Hostname contains `aluminumtrenchboxes.iconjds.com`). Saves the 5 fields to sessionStorage `ss_lt_hl_form`. Sends nothing.
- **SS - LeadTracker (Trench Box Thank You)** (Tag C) — Custom HTML, trigger **SS - Landing Page Lead** (existing: Page Path contains /ThankYou, Referrer contains the quote page — same as the Trench Box form conversion). ## Steps
1. LeadTracker server up? Open `https://leadtracker.smartsites.com/leadtracker-6.js` in a tab — it must load.
2. GTM Preview → `https://aluminumtrenchboxes.iconjds.com/get-free-quote/` → Connect. DevTools → Network, filter `leadtracker`, tick Preserve log.
3. Fill the form (Name `SS Test - please ignore`, test email, phone, city, organization), click **Get Your Quote**.
4. Tag Assistant, Click event: **SS - LeadTracker (Trench Box Quote Click)** fired. (Optional, before the redirect: DevTools → Application → Session Storage → `ss_lt_hl_form` holds the 5 fields.)
5. /ThankYou loads. Tag Assistant, Page View on /ThankYou: **SS - LeadTracker (Trench Box Thank You)** and **SS - Google Ads Conversion (Landing Page Lead)** (conv `Fz1UCI3hyc0BELzcz7UC`) fired once.
6. Network: `jquery-local-2.2.3.js` (200), `leadtracker-6.js` (200), then one request to leadtracker.smartsites.com sending the lead.
7. LeadTracker: test lead appears with the 5 fields. (Its page URL will be the /ThankYou page — `sendData` uses the current page.)
8. Negative check: click Get Your Quote with an empty required field → no /ThankYou → nothing sent.
9. Screenshots (red box): Tag Assistant Tag B on click, Tag C + conversion on /ThankYou, lead in LeadTracker.

## If it fails
- Tag B didn't fire: Click Text didn't match (check the Click event's Variables → Click Text). Clicking the icon/space inside the button can give empty text — click the words.
- Tag C fired but nothing sent: sessionStorage empty (Tag B didn't run, or /ThankYou opened on another host/tab) or LeadTracker server down.
- Tag C didn't fire: thank-you URL/referrer changed in HighLevel — compare with the Landing Page Lead conversion in the same Preview.
