Add the value variable

ChatGPT wants amount as a whole number in cents, so $129.99 becomes 12999. Use the real value key from step 1.

Add the booking goal tag

Custom HTML
<script>
(function () {
  var data = { type: "contents", currency: "USD" };
  var amount = {{cjs - oaiq amount (cents)}};
  if (amount) data.amount = amount; else delete data.currency;
  var opts = {};
  var tid = {{dlv - ecommerce.transaction_id}};
  if (tid) opts.event_id = String(tid);
  oaiq("measure", "order_created", data, opts);
})();
</script>

Watch for

  • Cookie banner. The pixel counts consent as given unless told otherwise. QCNY has a regional banner we couldn't see from our IP. If Richard wants the pixel to respect it, the base tag needs the same consent condition as the other marketing tags.
  • Content Security Policy. If the client's server sends one, it must allow bzrcdn.openai.com (scripts) and bzr.openai.com (requests and images). Otherwise the pixel loads in Preview but is blocked.
  • Shop purchases. shop.qcny.com runs a different container (GTM-WQPLWSW). It's out of scope unless Richard asks for gift purchases too.
  • One snippet per page. If the client's developer later adds the code to the site, pause the GTM base tag.
