Solution 3b: Any third-party IFRAME form with no thank-you page (only if one is found; Best Price turned out NOT to be one)
=================================================================================
Why it's different: GTM on ddmotors.com can't see clicks/submits inside an iframe from another domain
(browser security). The do.lead_submitted event above won't fire for it either (that's DealerOn's own forms only).
Only ways to track completion: the iframe tells the parent page (postMessage), or the vendor fires our pixel itself.

Step 1: Identify the vendor
   On the page with the form: DevTools > Elements > Ctrl+F "iframe" > note the iframe src domain
   (e.g. autofi.com / gubagoo / autoleadstar / other). Note the page URL + button text.

Step 2: Check if the iframe sends a message on submit
   DevTools > Console, paste and press Enter:
     window.addEventListener('message', function (e) { console.log('MSG from', e.origin, e.data); });
   Open the form, submit a TEST lead. Look for a new "MSG from <vendor domain>" line right after
   submit (e.g. data with "submit", "lead", "success", "complete"). Screenshot it.
   Ignore messages that also show on page load / typing; we want one that shows only on successful submit.

Step 3a: If a success message shows -> listen for it in GTM
   Tags > New > Custom HTML
   Name: SS - Listener - Best Price iframe submit
   HTML (replace VENDOR-DOMAIN and SUCCESS-TEXT with what Step 2 showed):
     <script>
       window.addEventListener('message', function (e) {
         if (e.origin.indexOf('VENDOR-DOMAIN') === -1) return;
         var d = typeof e.data === 'string' ? e.data : JSON.stringify(e.data);
         if (d.indexOf('SUCCESS-TEXT') === -1) return;
         window.dataLayer = window.dataLayer || [];
         window.dataLayer.push({ event: 'ss_best_price_submit' });
       });
     </script>
   Trigger: All Pages (or only the pages that have the form)
   Triggers > New > Custom Event
   Name: SS - CE - ss_best_price_submit        Event name: ss_best_price_submit
   Tags > New > Facebook Pixel (template)
   Name: SS - FB - Lead - Best Price
   Event Name: Standard > Lead
   Object Properties: content_name = form submit best price
   Trigger: SS - CE - ss_best_price_submit
   Check in GTM Preview: submit TEST lead -> ss_best_price_submit -> Lead tag fires once.
