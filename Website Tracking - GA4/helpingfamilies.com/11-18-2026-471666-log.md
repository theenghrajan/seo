## Step 1 — what BoldForm fires on submit
- `boldform-lite-frontend` JS (wpo-minify footer bundle): `$.ajax` POST to admin-ajax, `action=boldform_lite_submit_form`, FormData. `.done()` → redirect if `redirectUrl`, else adds `.boldform-lite-form__message.is-success` and resets form. `.fail()` → `.is-error`.
- **No custom DOM event, no dataLayer push.** So the agent's suggested `boldform_submit` (comment #4) never fires on its own; a listener is required.
- Contact form: `data-redirect-url=""`, `boldform_form_id=1`; fields text / email / tel / textarea + honeypot `boldform_hp_1`.
- Proposed listener (Custom HTML, Contact page or All Pages, fires on DOM Ready):
  ```html
  <script>
  jQuery(document).on('ajaxSuccess', function (e, xhr, s, data) {
    var fd = s && s.data;
    if (!(fd instanceof FormData) || fd.get('action') !== 'boldform_lite_submit_form') return;
    var r = data || xhr.responseJSON;
    if (r && r.success === false) return;
    window.dataLayer = window.dataLayer || [];
    dataLayer.push({ event: 'boldform_submit_success', form_id: fd.get('boldform_form_id') || '' });
  });
  </script>
  ```
  Then trigger `SS - Form Submission` = Custom Event `boldform_submit_success` (skill naming); point `form_submission` tag at it (add `form_id` param). Remove/pause the Formlets listener.
- Tested 2026-11-18 on live /contact/ in pw-firefox with a jQuery transport mock (admin-ajax answered in-browser with `{success:true}`; 1 request mocked, nothing sent to server, no lead/email): real submit handler ran → `is-success` message → `dataLayer` got `{event:'boldform_submit_success', form_id:'1'}`. Not yet tested in GTM Preview (listener not in GTM).
