## Correction (10-30)
- /services/residential-decks/ has BOTH the embedded LeadConnector form (`ix9cv3ijO8Ur2nTYYt1h`) and an HTML popup form `#popcontactForm` (method post, action "/"). Which one sent 10/16 and 10/20 is unknown, so the "LeadTracker cannot capture" line was removed from the comment.
- Live GTM v16 rules: event `form_submit_success` on ANY page fires tag 10 (GA4 lp_submit_lead_form), tag 22 (Ads label RbuzCK2hrescEIibuswD) and tag 39 (Bing). On /la-deck-builder it also fires tags 25, 27 (same Ads label again) and 29. `form_submit_success` comes from tag 33 `SS - Form Listener`, a MutationObserver that pushes on any added DOM node containing "thank". This is loose: any form's thank-you text, or any other dynamic "thank" text, on any page counts as the LP lead conversion. The Ads action is One per click, so tags 22 + 27 on the LP don't double count. Not changed (out of scope); raise with the user.
